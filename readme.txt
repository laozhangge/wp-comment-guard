给老评论里的外部链接做分级与体检：久未往来的访客链接降为纯文本，域名被抢注成博彩/色情/诈骗站的自动拦下，抓不到的一律不降级。

== Description ==

博客写久了，评论区会攒下几千个外链。这些链接会变——十几年前一起写博客的人早就不写了，域名到期被买走，现在指向博彩站，链接还挂在你的文章下面。

手工一条条点开看不现实：两万条评论，一天点五十个也要一年。本插件把这个过程自动化，只做一件事：**判断这条链接现在还能不能点**。

**核心思路不是"猜它坏不坏"，而是"看它还是不是那个人的站"：**

1. **先看人** —— 近一年还在你这里留言的，链接直接放行，一个页面都不去抓；五年以上毫无来往的，归档降级。
2. **再看站** —— 落在中间这段的才抓首页，看它现在是什么：个人博客、企业站、交易所、还是域名待售页。

实测一个两万条评论的站点，真正需要抓取的域名只有 325 个，其余在第一关就处理完了。

**它不会做的事（很重要）：**

* 不修改、不删除任何评论数据。所有降级都是渲染时把 `<a>` 换成 `<span>`，撤掉插件即恢复原状。
* 抓不到就不下结论。DNS 失效、被防火墙拦、超时、返回空白页——一律不降级。
* 不向任何第三方上报数据。运行时唯一的外部请求是抓取待检域名的首页。

**主要功能：**

* 评论作者网址与正文外链分级（纯文本降级，源码里不再出现该域名）
* 站点体检：风险站 / 域名待售页 / 死链 / 已不是个人站 / 暂无指纹
* 后台六张清单：风险、已废弃、已不是个人站、暂无指纹、待复核、已失效链接
* 域名速查：粘一个域名，摊开判定链每一步，看得见为什么被降、为什么被放行
* 黑白名单（白名单带保护期，到期重新检测）
* 提交时拒绝黑名单域名（可开关）
* 本机抓取助手：服务器在海外抓不到的站，用你自己的电脑抓、结果回传
* 自动轮转体检（WP-Cron，可按间隔复查）
* 异常播报：菜单徽章 + 仪表盘卡片，只报"新增了什么"

== Installation ==

1. 后台 → 插件 → 安装插件 → 上传插件，选择 zip 包，启用。
2. 左侧菜单出现「外链守卫」，进入「设置」按需调整（默认值基本可用）。
3. 进入「外链体检」，点「连续扫描到完成」，完成第一次体检。
4. 扫完之后每小时会自动复查一批到期的域名，不用再管。

首次扫描耗时参考：约 2~4 秒/个域名。100 个约 5 分钟，500 个约 25 分钟，2000 个约 2 小时。

== Frequently Asked Questions ==

= 装好之后前台没有任何变化？ =

先确认做过一次扫描。插件刚装时体检表是空的，所有链接只按"往来时间"放行，它还没看过任何域名的内容。

如果扫过了仍无变化，多半是页面缓存。降级发生在渲染时，缓存插件存的是替换后的页面。插件会自动清理 WP Rocket、LiteSpeed、W3TC、WP Super Cache 等常见缓存，用 CDN 的话需要手动清一次。

= 某个正常博客被降级了？ =

去「外链体检 → 域名速查」粘贴该域名，能看到判定链每一步的结果，一眼看出是哪一层判的。
确实是误判就点「加入白名单」，之后不再参与判定。判据永远有误差，白名单就是留给人纠错的。

= 某个域名一直显示"抓不到"？ =

多半是该站 IP 被对方防火墙拦了，或者站点只对特定地区开放。插件内置「本机抓取助手」，在你自己的电脑上运行一个小脚本去抓、结果回传，判定标准与服务器完全一致。

= 会不会误伤正常访客？ =

近一年来留过言的访客，链接一律放行，不做任何站点判定。会被降级的只有两类：确实变成黄赌、诈骗、待售页的，以及五年以上毫无来往的。

= 停用或卸载会丢数据吗？ =

停用：数据全部保留，前台恢复成不做任何处理（链接全部可点）。
卸载（删除插件）：会清空体检表与黑白名单，不可逆——两万个域名重扫要几个小时。只是想关掉的话，停用就够了。

= 需要什么运行环境？ =

WordPress 5.5+、PHP 7.4+，服务器需要能访问外网（要用 curl 抓待检域名的首页）。
